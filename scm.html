Stock Count Management

An Oracle APEX application for stock-count sessions, printable QR-linked sheets, and recount cycles, with Odoo file import and export.

Focus

Stock-count sessions, count sheets & recount cycles

Built with
  • Oracle APEX

The context

SCM is designed for Finance and Accounting teams auditing warehouse stock. It organizes quarterly and annual stock-count sessions, including annual counts split into parts. Location-based count sheets, review cycles, and Odoo file exchange support the count from preparation to its final export. The application has not yet entered operational use.

The stock-count workflow

Prepare, count, review, and recount.

  1. 01

    Organize count sessions and their history

    Quarterly and annual counts are organized as separate sessions, with annual counts also divided into parts. Past sessions are documented and can be restored when needed.

  2. 02

    Create a session from an Odoo stock file

    An Odoo stock_quant file can be uploaded into SCM to create a new stock-count session.

  3. 03

    Generate count sheets by location

    Stock lines are divided into location-based count sheets, called papers in the application. Each paper can be generated as a printable PDF for the count.

  4. 04

    Manage line-level recount cycles

    Each paper has a count cycle. Rejected lines generate a new paper and a new cycle, allowing items to be counted again as needed.

    A supervisor can force-accept a discrepant line when needed.

  5. 05

    Open the matching sheet from its QR code

    Each PDF includes a QR code containing the paper’s ID. Scanning it inside SCM opens that count sheet directly.

  6. 06

    Export count results back to Odoo

    The stock-count result can be exported as a CSV file for import back into Odoo.
