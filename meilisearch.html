Meilisearch Integration

Direct product suggestions in the search bar, backed by daily index rebuilds and product-focused relevance tuning.

Focus

Product suggestions, indexing & relevance

Built with
  • Python
  • Meilisearch
  • BigQuery
  • Cloud Run Jobs

Search performance

SKUs indexed
6M
click-through rate on product suggestions
5%

CTR refers to clicks on product suggestions in the search bar.

The context

The previous search bar suggested search terms: typing “Paper” could suggest searching for “Paper” again. With Meilisearch, the dropdown shows matching paper products directly. Backend indexing and relevance configuration support the product suggestions presented in the search bar.

The search experience

From a query to a product.

  1. 01

    Show matching products in the search bar

    Typing “Paper” brings up matching paper products in the search-bar dropdown. Indexing, result-field selection, and ranking configuration provide the backend support for those product suggestions.

  2. 02

    Rebuild the catalog index every day

    A Cloud Run job queries product data stored in BigQuery and builds a fresh Meilisearch index each day. The catalog contains around six million SKUs. The active index is switched only after the replacement is built successfully; the old index is then removed. Products absent from the new snapshot are excluded.

    A failed rebuild triggers an automatic retry. If that also fails, the existing index remains active and rebuilding is attempted again another day.

  3. 03

    Tune relevance around product attributes

    Model, brand, and product name are the key product fields for relevance. Search counts and purchase counts are included as ranking inputs, with synonyms configured to connect related search terms. The configuration also determines which product fields are returned for the suggestions.

Observed result

Product suggestions in the search bar recorded a 5% click-through rate.
