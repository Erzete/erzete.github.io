MyPanel

A web and mobile application for learning about solar panels, exploring products, and estimating installation costs.

Focus

Solar panel discovery & cost estimation

Built with
  • Python
  • Django
  • Flutter

The context

Built as the final project for Platform-based Programming. MyPanel brings solar panel information, shopping, and an installation cost calculator into a web and mobile experience.

What it does

  • Help people learn about solar panels.
  • Provide a way to browse and purchase solar panel products.
  • Estimate the cost of installing solar panels in a building.
