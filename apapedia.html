Apapedia

An e-commerce platform with a web interface for sellers and a mobile application for buyers.

Focus

Seller web & buyer mobile experiences

Built with
  • Java
  • Spring Boot
  • Flutter
  • Docker

The context

Built as the final project for Enterprise Application Architecture and Programming. The platform serves two sides of e-commerce: sellers list products and track sales on the web, while buyers use a mobile frontend.

What it does

  • Give sellers a web interface to list products.
  • Support sellers in tracking sales.
  • Provide buyers with a separate mobile frontend.
