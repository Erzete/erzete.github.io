ChatDesk

A Zendesk sidebar app for customer WhatsApp conversations, ticket-to-template field mapping, and outreach logging.

Focus

Customer conversations & template outreach inside Zendesk

Built with
  • Zendesk app
  • Python
  • Chatwoot
  • Meta WhatsApp API

The context

Customer service already used Zendesk for tickets, but WhatsApp outreach meant switching tabs and copying ticket values into message templates. ChatDesk provides a custom Zendesk sidebar interface connected to Chatwoot, with ticket fields mapped into the app and WhatsApp templates. An earlier usage check put total message volume at roughly 50–100 messages per day.

The support workflow

Customer outreach, beside the ticket.

  1. 01

    Open the right customer conversation

    The customer phone number on the Zendesk ticket is mapped into ChatDesk’s custom sidebar interface. The interface connects to Chatwoot so agents can review the customer’s messages and send a WhatsApp message while staying inside Zendesk.

  2. 02

    Prepare WhatsApp templates from ticket fields

    Zendesk fields map to app inputs and WhatsApp template parameters, reducing repeated copying between tools. The ChatDesk backend calls Chatwoot, which sends the message through the Meta WhatsApp API.

  3. 03

    Keep template outreach in the ticket record

    Each template message send is recorded in its Zendesk ticket, keeping a record of the outreach alongside the support work.
